# Tela de Login em Python

Projeto simples de uma tela de login desenvolvida em Python utilizando a biblioteca CustomTkinter.

Imagens/image.png


## Tecnologias

- Python 3
- CustomTkinter

## Funcionalidades

- Interface gráfica moderna
- Campo de usuário
- Campo de senha com caracteres ocultos
- Validação das credenciais
- Feedback visual de sucesso ou erro

## Como executar

1. Clone o repositório

```bash
git clone https://github.com/DefaultCode01/tela-login-python.git
```

2. Instale a biblioteca

```bash
pip install -r requirements.txt
```

3. Execute

```bash
python main.py
```
